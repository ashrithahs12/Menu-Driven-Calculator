# Console-Based Smart Calculator 🧮

## 📌 Project Overview

The **Console-Based Smart Calculator** is a Python-based mini project that performs various mathematical operations through a simple menu-driven console interface.

The project uses Python functions to perform arithmetic calculations and the NumPy library to perform array addition. Users can select an operation, enter the required values, view the result, and continue performing calculations until they choose to exit.

## 🎯 Objectives

- To develop a menu-driven calculator using Python.
- To perform different arithmetic operations.
- To implement functions for modular and reusable code.
- To perform array addition using NumPy.
- To provide a simple console-based user interface.

## ✨ Features

The calculator supports the following operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Floor Division
6. Power
7. Modulus
8. NumPy Array Addition
9. Exit

**Additional features:**
- Menu-driven interface.
- Repeated calculations without restarting the program.
- Division-by-zero handling for division and modulus.
- NumPy-based array addition.

## ⚙️ Installation and Setup

**Step 1: Clone the repository**

```bash
git clone https://github.com/ashrithahs/Console-Based-Smart-Calculator.git
```

**Step 2: Navigate to the project folder**

```bash
cd Console-Based-Smart-Calculator
```

**Step 3: Install the required library**

```bash
pip install numpy
```

**Step 4: Run the program**

```bash
python calculator.py
```
